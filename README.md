# Automated testing and model checking with Copilot

To demonstrate how Copilot can assist in the development of a stable and precise implementation,
the "Profit Triplet" problem (Leetcode 2921) is being progressively implemented in golang, with
automated testing and partial formal verification performed incrementally.

### Repository Overview

- **agent/** contains a daily summarized transcript of the collaboration between developer and Copilot
- **cmd/** app entry point
- **internal/** core implementation in dag.go, plus an internal unit test
- **model/** techniques and results
  - **bug/** reports found by automated testing and model checking
  - **doc/** diagrams and an overview of testing and proof results
  - **meta/** BNF for the inline symbolic execution grammar, plus Copilot rules for generating proofs and diagrams
  - **proof/** sub-goal proofs generated by Copilot
- **pkg/util/** go helper functions
- **test/** external tests
